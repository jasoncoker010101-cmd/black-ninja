# Black Ninja

A browser-based 3D arena game built with Three.js.

## Run the game
Open `index.html` through a static web server or GitHub Pages. The game uses Three.js from jsDelivr.

## 3D scenery
The arena loads low-poly GLB trees, bushes, rocks, and grass from Gobkit's Nature Kit. The pack is published under CC0 1.0, which permits use and modification without attribution. If a remote scenery model cannot load, the game creates a simple fallback prop so the arena remains playable.

See [ASSET_CREDITS.md](ASSET_CREDITS.md) for asset source and license notes.

## Controls
- WASD: Move
- Mouse: Look around
- Click or Space: Action
- Shift: Run
- Escape: Pause
